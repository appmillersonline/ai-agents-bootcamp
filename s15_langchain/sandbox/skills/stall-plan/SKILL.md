# Stall plan: Sara's house style

Write the plan to a Markdown file with exactly these sections:

1. **The market**: one line with the name, the dates and the place.
2. **Why this one**: two short sentences.
3. **What to bring**: a table with Product, Units and Price (euros). Use only these products and prices:
   - Candle trio, 22 euros
   - Lavender candle, 12 euros
   - Speckled mug, 14 euros
   - Linen tote bag, 18 euros
4. **Before the market**: a checklist of at most five items, starting with the application deadline.
5. **One risk**: one sentence, and what Sara can do about it.

Rules: short sentences, no hype words, no emoji. If a fact like a date or a fee is not certain, write "check with the organiser".
