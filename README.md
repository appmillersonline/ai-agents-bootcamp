# AI Agents Bootcamp

The code for every lecture, section by section.

## Get started

1. Install uv and git (see Section 0).
2. In this folder, run `uv sync`.
3. Copy `.env.example` to `.env` and paste your API key.
4. Run your first AI call: `uv run s00_start_here/first_call.py`
